Preferências gerais

Dados locais

Suas movimentações, metas, cartões e faturas ficam salvas no banco de dados do FinanCerto e não são apagadas aqui. Este botão remove só o que fica guardado neste navegador: preferências desta página, regras de alerta por categoria e dados de perfil em cache.

Sobre

FinanCerto — sistema de controle financeiro pessoal.
Front-end: HTML, CSS e JavaScript puro.
Back-end: Java + Spring Boot, com banco de dados MySQL via API REST.

🗑

Limpar dados deste navegador?

Isso remove as preferências desta página, as regras de alerta por categoria e o perfil em cache salvos neste navegador. Seus lançamentos, metas e cartões no banco de dados continuam intactos. Essa ação não pode ser desfeita.
